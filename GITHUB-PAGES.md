# GitHub Pages — LuminateDigitalDesign

1. GitHub → Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
2. Add the custom domain after it is chosen/owned.
3. Replace `YOUR-DOMAIN.com` in `robots.txt` and `sitemap.xml`.
4. Replace the placeholder inbox in `script.js`.

Publishing status should only be considered live after Pages is enabled and the generated URL is verified.
